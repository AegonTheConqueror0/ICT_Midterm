# HCDC COME - Shipboard Computer Hardware & Network Design Simulator
### BSMT Midterm Laboratory Assessment Platform

An interactive maritime computer-based assessment system developed for the **College of Maritime Education (COME)** at **Holy Cross of Davao College (HCDC)** for **Bachelor of Science in Marine Transportation (BSMT)** cadets.

---

## Features

- **Cadet Registration Gate:** Required credential verification before exam launch; navigation tabs remain locked and 30-minute timer remains paused until started.
- **Module 1 - Hotspot Labelling (30 pts):** Marine computer hardware identification & bridge application analysis.
- **Module 2 - Component Matching (15 pts):** Maritime hardware components to operational functions.
- **Module 3 - Network Topology Builder (30 pts):** Interactive bridge network cabling (ECDIS, Radar, AIS, GPS, and Industrial Switch).
- **Module 4 - Checking & Handling (25 pts):** Shipboard fault troubleshooting and 6-step equipment handling sequence.
- **Module 5 - Official Receipt & PDF Download:** Anti-tamper receipt generator with one-click official PDF export.
